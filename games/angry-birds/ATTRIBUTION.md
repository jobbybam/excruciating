# Angry Birds browser remake

This folder contains the JavaScript game “AngryBirds,” authored by Mahdi7s and tonikolaba. The upstream repository includes its MIT licence in `Licence.md`; that notice is preserved here. The game is an unofficial browser remake. Angry Birds and its original characters and marks belong to Rovio Entertainment.

Source: https://github.com/olivia-games/game/tree/main/angry-birds

The tile and home-screen icon use the red bird sprite from this game build.
