# Brick Breaker

An original, self-contained browser game created for Excruciating Leg Pain.

## Run

Open `index.html` through the site's local game player. The game has no external runtime, network dependency, or third-party game assets.

## Controls

- Desktop: Left/Right arrows or A/D to move; Space or Enter to launch; P to pause.
- Touch: Drag or tap within the playfield to move and launch.
- Mouse: Move the pointer across the playfield to steer the paddle.

The game stores the best score in the browser's local storage.
